# Deployments

Deployment status for the NOX protocol.

## Testnet: Arbitrum Sepolia (chain ID 421614)

Live since 2026-09-25, with 13 registered nodes. Registry deployment block: `312414608`.

Governance: a Timelock (`0xe128389c997a7Ff0CB921b257547e497c5FA9c11`, 0 s delay on this testnet) holds the
admin and upgrader roles. A 3-of-5 governance Safe (`0x776652ab08563Ffd39043a259B6d6B5F7dFf1ae2`) is its only
proposer and executor, and it registers nodes. A 2-of-3 guardian Safe
(`0x248dEb4eD675e5b727f199E32D3675aa284612F5`) is the DarkPool pauser, the NoxRegistry slasher, and the
NoxRewardPool admin and distributor.

Node operators get the complete record, with runtime code hashes, proxy implementation slots and pinned node
images, from [`run-nox/configs/arbitrum-sepolia.deployment.json`](https://github.com/hisoka-io/run-nox/blob/main/configs/arbitrum-sepolia.deployment.json).

### Retired

The April 2026 Arbitrum Sepolia registry `0x8626aF80db409BeD3C19871FAdf9b0Ce7Aa641Bc` was retired on 2026-09-25.
It exposes the old seven-field profile ABI and cannot satisfy the SDK's complete topology verification.

## Seed nodes

The SDK resolves seed nodes automatically via the seed API (`api.hisoka.io/seed`). You can also pass explicit seeds:

```ts
const client = await NoxClient.connect({
  seeds: ["https://api.hisoka.io/seed"],
  ethRpcUrl: "https://arb-sepolia.g.alchemy.com/v2/YOUR_KEY",
  registryAddress: "0xF7BFf88A1412054a001Dc4b8aCBddAd6F9b26cB6",
});
```

## On-chain verification

Topology verification is mandatory outside an explicit loopback test mesh:

```ts
const client = await NoxClient.connect({
  ethRpcUrl: "https://arb-sepolia.g.alchemy.com/v2/YOUR_KEY",
  registryAddress: "0xF7BFf88A1412054a001Dc4b8aCBddAd6F9b26cB6",
});
```
