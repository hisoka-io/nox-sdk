# Deployments

Deployment status for the NOX protocol.

## Testnet

The previous Arbitrum Sepolia Registry is retired. It exposes the old seven-field profile ABI and cannot satisfy
the SDK's complete topology verification. No current paid-execution deployment is published yet.

The next release will publish the Registry proxy and implementation, RewardPool proxy and implementation,
NoxEntryPoint, sandbox implementation, payment adapter, BundleExecutor, runtime code hashes, proxy slots, fee
assets, and start block in one signed deployment record. Clients and operators must consume that record instead
of copying an address from historical documentation.

## Seed nodes

The SDK resolves seed nodes automatically via the seed API (`api.hisoka.io/seed`). You can also pass explicit seeds:

```ts
const client = await NoxClient.connect({
  seeds: ["https://api.hisoka.io/seed"],
  ethRpcUrl: "https://arb-sepolia.g.alchemy.com/v2/YOUR_KEY",
  registryAddress: "0xCURRENT_NOX_REGISTRY",
});
```

## On-chain verification

Topology verification is mandatory outside an explicit loopback test mesh:

```ts
const client = await NoxClient.connect({
  ethRpcUrl: "https://arb-sepolia.g.alchemy.com/v2/YOUR_KEY",
  registryAddress: "0xCURRENT_NOX_REGISTRY",
});
```
